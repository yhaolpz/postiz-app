## 可直接归因的事实

1. 能浏览、检索和执行动作的 Agent 会接触外部内容；提示注入会把藏在外部内容里的指令伪装成用户想要的任务。
2. 只过滤恶意输入不够。即使外部内容操纵成功，系统也要限制它能造成的影响。
3. OpenAI 使用“源—出口”的视角：不可信来源与敏感出口的组合，例如传出信息、点击链接或调用工具，是高风险组合。
4. 文章举例说明：对可能传出的信息展示给用户并请求确认，或在相关应用发现异常通信时征求同意，能够把敏感动作从静默执行改为可审查决定。
