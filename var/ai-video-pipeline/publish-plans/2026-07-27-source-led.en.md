### 2026-07-27 Sun - Learn Without Retraining

- Source: Reflexion, Language Agents with Verbal Reinforcement Learning, NeurIPS 2023
- Tiny point: Reflexion turns feedback from an attempt into a verbal reflection stored in episodic memory. That reflection changes the next attempt without updating the model weights.
- Hook: Does one failed task mean an agent must retrain its model?
- Narration: Does one failed task mean an agent must retrain its model? Reflexion offers another path. After an attempt, the agent reads feedback and writes a short reflection: what went wrong, and what should change next time. It stores that note in episodic memory, then brings it back as context for the next attempt. Imagine a code test fails because empty input was missed. A useful reflection says exactly that, not just try harder. On the next plan, the agent checks empty input before it retries. The model weights stay the same. What changes is the experience text the agent can see. This is a research framework, not a guarantee: weak feedback gives weak reflections. Tiny Rule: feedback must be specific, actionable, and relevant to the next task. Follow Tiny Agent. Tiny Agent helps you get better at using AI.
