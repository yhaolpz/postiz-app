### 2026-07-26 Sun - ReAct Updates the Plan

- Source: ReAct, Synergizing Reasoning and Acting in Language Models, ICLR 2023
- Tiny point: ReAct alternates reasoning with actions. Actions bring back information from a knowledge base or environment, and the next reasoning step updates the plan from what was observed.
- Hook: Should an agent plan everything first, then execute it all at once?
- Narration: Should an agent plan everything first, then execute it all at once? ReAct proposes a different loop: reasoning and action take turns. Reasoning picks the next thing to verify. Action checks a knowledge base or the environment. Then an observation comes back, and the agent updates its next decision. Imagine planning a trip. Check the weather first. If a storm appears, change the route or date instead of following the old plan. Thinking without action can use stale facts. Action without reasoning becomes blind clicking. ReAct matters because outside evidence enters the next decision. Tiny Rule: make one judgment, run one check, then update the plan from what you observed. Follow Tiny Agent. Tiny Agent helps you get better at using AI.
