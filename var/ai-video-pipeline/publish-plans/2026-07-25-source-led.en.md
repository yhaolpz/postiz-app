### 2026-07-25 Sat - Give Agents an Exit

- Source: OpenAI, A practical guide to building agents, cross-checked with Anthropic, Building effective agents.
- Tiny point: An agent run is a loop and needs task-matched exit conditions: final output, a specified structured output, no more tool calls, an error or human handoff, and bounded turns; teams can also bound time, cost, and retries to prevent repeated failure from expanding.
- Hook: A busy agent can work forever.
- Narration: A busy agent can work forever. OpenAI describes an agent run as a loop that keeps going until it reaches an exit condition. One exit is a final answer, or a required structured result. Another is when the model stops asking for tools and is ready to respond. Errors, missing permission, or a risky judgment should stop the run and return control to a person. Set limits for turns, time, cost, and retries so a failure cannot grow forever. For example, a research agent can stop when its evidence meets the task standard, not when it has searched the entire internet. The limit should fit the task, not force every job into the same number of turns. Tiny Rule: define a success exit, a failure exit, and a budget exit before the loop begins. Follow Tiny Agent. Tiny Agent helps you get better at using AI.
