# Distribution boundary

- This directory may validate, import, stage, publish, update, and clean up
  Postiz-owned distribution copies.
- Video research, scripts, TTS, subtitles, timelines, scenes, rendering,
  covers, metadata authoring, and production QA belong to
  `/Volumes/SSD/Workspace/seek/apps/video-production`.
- Treat every Seek release bundle as immutable and read-only.
- Never modify or delete a Seek source project, master, or release bundle.
- Importing a bundle is not publication. Platform publication requires a
  separate explicit command and authorization.
