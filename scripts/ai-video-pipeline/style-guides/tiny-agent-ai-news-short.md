# Tiny Agent「AI 上新白话」中文短视频准出标准

适用范围：Tiny Agent 抖音账号中，面向非专业用户介绍 AI 新工具、新功能、新模型的中文竖屏短视频。

本标准只约束「AI 上新白话」短视频，不替代 Tiny Agent 现有长视频规范。

## 修订依据

| 已确认结论 | 证据 | 对成片的约束 |
| --- | --- | --- |
| 旧样片信息密度过高 | 同屏出现网格、细线、页面编号、多张卡片和小字号说明 | 删除常驻网格、装饰线、页面编号、二维码块和无信息价值的 UI |
| 重点不够突出 | 同一镜头同时解释多个概念 | 一个镜头只保留一个观点，讲完再切换 |
| 缺少产品可信度 | 旧样片用抽象卡片替代真实界面 | 必须使用官方产品或官方功能截图；拿不到截图的选题不进入制作 |
| 选题偏离主流关注 | 旧样片以 Cursor Router 为主题 | 选题优先覆盖 Codex、Claude Code、ChatGPT/OpenAI 模型、Gemini、Kimi、DeepSeek |

## 选题

### 优先级

1. Codex、ChatGPT 与 OpenAI 新模型。
2. Claude Code 与 Claude 新模型。
3. Gemini 新模型及其核心产品功能。
4. Kimi、DeepSeek 的新模型与主流产品功能。
5. 其他产品只有在国内讨论度明显上升，或出现足以改变普通用户使用方式的重要更新时才进入候选。

Cursor 等工具不作为日常主线；只有重大版本、广泛讨论或明显改变使用方式的功能才进入候选。

### 选题门槛

- 优先选择过去 72 小时内的官方更新；常规选题最长不超过 7 天。
- 每条视频只回答一个问题：`这个新东西是什么`、`它解决什么问题` 或 `小白现在怎么用`。
- 不做同一期多产品新闻汇总，不在一个镜头里堆叠多个模型名。
- 事实必须来自官方产品、官方博客、官方文档、官方发布说明或官方开源仓库。
- 选题确定前必须确认至少一张可用的真实产品或功能截图。

## 真实截图

- 每条视频至少使用一张真实截图，优先顺序为：真实产品界面、官方功能演示、官方发布页面。
- 截图必须直接对应旁白正在解释的功能，不能只放品牌首页或无关装饰图。
- 截图是主体画面，不是角落里的佐证：主要截图在对应镜头中应占中央内容区的 55% 以上。
- 可以裁切、放大、平移和加单一高亮框，但不得重绘、伪造或补造产品 UI。
- 截图内文字较小时，必须用大号中文覆盖层复述当前唯一重点；不要求观众阅读截图中的全部小字。
- 无法获得真实截图、截图来源不明或截图无法证明功能时，选题准出失败。

## 画面

- 固定规格：`1080×1920`、30 fps、H.264 + AAC。
- 使用干净的纯色或极轻微明暗层次背景；不使用常驻网格、密集线条、页面编号、二维码块、数据仪表盘或无意义装饰。
- 每个镜头最多三个主要视觉元素：一个大标题、一张真实截图、一个 Tiny Agent。
- Tiny Agent 延续现有角色形象，但只承担引导和陪伴作用，不能遮挡截图或成为信息主体。
- 一个镜头只强调一个区域；除字幕外，不同时展示两个解释段落。
- 动画只服务于看清重点：短距离进入、截图缓慢放大、单次高亮。一个元素最多一种主要动画，不使用持续漂浮、抖动或复杂路径。

## 字体与字幕

- 中文标题使用清晰的无衬线粗体，字重 800–900，首轮设计字号不低于 96 px。
- 辅助说明字重不低于 700，字号不低于 48 px。
- 单个标题建议不超过 12 个汉字；超过时拆镜头，不缩小字体硬塞。
- 中文字幕使用短语级同步，每屏最多两行，字号不低于 54 px。
- 字幕区位于 `y=1450–1780`；标题、截图关键区域和 Tiny Agent 面部不得进入字幕区。
- 不使用微型标签、英文页面编号、装饰性参数或必须暂停才能看清的说明文字。

## 结构与节奏

- 建议时长 25–45 秒，4–5 个镜头，每个镜头约 4–8 秒。
- 推荐结构：三秒钩子 → 新功能是什么 → 真实界面怎么找到 → 小白怎么选或怎么用 → 一句行动建议。
- 旁白先说结论，再补最少必要解释；专业术语第一次出现时立即翻译成日常语言。
- 每个镜头的画面重点必须与当前旁白完全一致，不提前展示下一段信息。
- 默认中文声音为 `zh-CN-YunxiaNeural +40%`，保持清楚但更紧凑；语气像朋友解释，不喊口号、不念参数表。
- 默认不加背景音乐；只有音乐不会影响小白理解时才单独评估。

## 准出检查

成片必须同时满足以下条件：

1. 前三秒能看懂产品名和本期唯一主题。
2. 至少一张真实产品或功能截图清楚可见，来源可以追溯到官方 URL。
3. 任一暂停画面都没有信息堆叠；一个镜头只有一个明显视觉中心。
4. 标题、辅助说明和字幕达到最小字号，没有依靠小字传递核心信息。
5. 没有常驻网格、密集线条、二维码块、页面编号、伪造 UI 或纯文本连续镜头。
6. 最终 MP4 通过 HyperFrames 检查，并从最终视频抽取关键帧人工查看。
7. 未通过真实截图、可读性或单点表达检查时，不得进入发布流程。

机器检查命令：

```bash
node scripts/ai-video-pipeline/validate-tiny-agent-ai-news-short.mjs \
  --project videos/<project> \
  --require-render
```
