# Visual direction

产品截图占画面中心，中文大标题负责解释当前唯一重点。背景使用纯深灰，不使用网格、常驻线条、二维码、页码、数据仪表盘或装饰性小字。

每个镜头最多包含：

1. 一个大标题。
2. 一张真实产品或官方功能截图。
3. 一个 Tiny Agent；只有开头或结尾需要。

截图使用短距离进入和一次缓慢放大。标题快速出现后保持稳定，不使用逐字特效。字幕位于画面底部独立安全区。
