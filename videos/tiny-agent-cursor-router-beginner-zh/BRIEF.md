## Intent

为 Tiny Agent 账号制作一条中文竖屏样片，用最少术语解释 Cursor 于
2026 年 7 月 22 日发布的 Cursor Router。重点不是罗列模型，而是让小白
理解：选择 Auto 后，系统会按任务复杂度路由模型；三个优化模式分别偏向
效果、平衡和成本。

- `.media/images/image_003.png` — Tiny Agent 接收工具姿势，用于解释“任务被交给合适模型”。

## Customizations

- 使用 Tiny Agent 现有纸张网格、黑色粗线、蓝色重点和少量红色提醒的视觉语言。
- 中文字幕最多两行；专业词第一次出现时立即翻译成普通人的说法。
- 画面只使用一个 Tiny Agent，产品能力通过任务卡、模型卡和三档选择器表达。
