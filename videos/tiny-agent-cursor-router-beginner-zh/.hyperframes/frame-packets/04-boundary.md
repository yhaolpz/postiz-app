**keyMessage:** Router 是降低选择成本，不是取消判断和费用。

**Scene 1 (0.000–2.500s):** 顶部卡片从左翼进入并带轻微正向 `rotateY`：“改一句文案 / 不必先上最贵模型”；Tiny Agent 在卡片旁观察。

**Scene 2 (2.500–5.200s):** 下方卡片从右翼进入并带镜像 `rotateY`：“复杂重构 / 需要更强能力”；两张卡大小相同，形成纵向对照。

**Scene 3 (5.200–7.700s):** 两条相反方向的蓝色路线箭头分别连接到“轻量选择”和“更强选择”，说明任务不同、结果不同。

**Scene 4 (7.700–10.488s):** 两枚红色方章依次盖下：“不保证永远最好”“成本模式 ≠ 免费”；章印只弹一次，随后静止保持。
