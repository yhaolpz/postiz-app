**narrativeRole:** 把三个官方模式翻译成三个普通人的选择目标。

**keyMessage:** 小白不用选模型，只需选择自己更在意效果、平衡还是成本。

**Scene 1 (0.000–1.600s):** 标题“你只选一个目标”从上方短距落定，空的纵向三格区域同时建立。

**Scene 2 (1.600–4.000s):** 第一张方角卡短距滑入自己的槽位：“智能优先 / 更看重效果”；只让蓝色序号轻弹一次。

**Scene 3 (4.000–6.600s):** 第二张卡滑入：“平衡模式 / 效果和日常兼顾”；蓝色边框与左侧标记将它设为默认建议，Tiny Agent 指向这一格。

**Scene 4 (6.600–8.700s):** 第三张卡滑入：“成本优先 / 先控制 Token 支出”；不出现“免费”字样。

**Scene 5 (8.700–9.312s):** 三张卡共同保持，中央“平衡模式”仍是唯一高亮项。
