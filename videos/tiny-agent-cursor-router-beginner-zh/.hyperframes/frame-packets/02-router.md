**narrativeRole:** 把 Router 这个陌生术语变成“快递分拣”一样熟悉的动作。

**keyMessage:** Auto 会先判断任务，再选择模型。

**Scene 1 (0.000–2.500s):** 镜头打开在中央站点“Cursor Router”，下方用更大的中文解释“自动分流器”；一条蓝色路线向右延伸。

**Scene 2 (2.500–5.500s):** 虚拟镜头平移到“你的任务”站，一张只写“帮我改代码”的纸卡滑上路线；Tiny Agent 接收工具姿势在右侧托住任务卡。

**Scene 3 (5.500–8.500s):** 镜头沿路线依次经过“判断任务 / 看复杂度”两个标记，最终停在“交给合适模型”站；只表现因果链，不绘制真实 Cursor 界面。

**Scene 4 (8.500–9.456s):** 三个站点缩略为一条清楚的静态路径“任务 → 判断 → 合适模型”，终点蓝色描边加深并保持。
